调用过程#

Cgo 将Go代码编译成动态链接库，然后Java通过JNA 来调用动态链接库

1

Go ---> Cgo --> Shared libraries <--- JNA <--- Java

名词解释

Cgo：Go和C的桥梁，两者可以互相调用

JNA：一个Java框架，让Java程序更方便地使用动态链接库

Shared libraries: 动态链接库1
